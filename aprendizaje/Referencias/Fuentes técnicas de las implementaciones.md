# Fuentes técnicas de las implementaciones

Estos enlaces son referencias de formato/API, no licencias transferidas ni pruebas nuevas de instalación. Consultar documentación vigente antes de implementar. No se incluyen bundles ajenos.

- JSON Canvas, estructura de nodos y aristas: https://jsoncanvas.org/spec/1.0/
- ActivityWatch, documentación y REST API: https://docs.activitywatch.net/
- TaskNotes, funciones y contrato de tareas: https://tasknotes.dev/obsidian/features/
- Syncthing, ignorados: https://docs.syncthing.net/users/ignoring.html
- Syncthing, versionado y límites: https://docs.syncthing.net/users/versioning.html
- rclone bisync, recuperación y conflictos: https://rclone.org/bisync/
- SQLite, API de backup consistente por base: https://www.sqlite.org/backup.html
- Python, backup SQLite y lectura URI: https://docs.python.org/3/library/sqlite3.html
- Linux, file leases y bloqueos: https://man7.org/linux/man-pages/man2/fcntl.2.html
- GTK 3 / Pango, visor flotante como implementación posible: https://docs.gtk.org/gtk3/ y https://docs.gtk.org/Pango/
- List Modified, registro técnico de enlaces: https://github.com/franciskafieh/obsidian-list-modified

El visor flotante local no se copia: dependencia gráfica y rutas necesitan una revisión de redistribución y prueba separada. Los métodos no requieren adoptar marcas, hardware, plugins ni servicios concretos.

Origen: síntesis nueva de prácticas locales revisadas; no incorpora fuentes privadas ni código de terceros.
